# FoxBox Swing – Schaukel-Simulator

Browser-Simulator für die mohap-Schaukel im FoxBox-Look: 6 Schaukeln, 6 Instrumente, 6 Lichter.
Je höher eine Schaukel schwingt, desto mehr spielt ihr Instrument (3 Stufen).
Schwingen mindestens drei im Gleichtakt, öffnet sich der Klang und alle Lichter blitzen.

Stile: Italo Disco, House, Techno, Lo-Fi Hip-Hop, Ambient. Alle Klänge werden live mit der Web Audio API erzeugt – keine Samples.

**Live:** https://joemoe.github.io/foxbox-swing/

Bedienung: Schaukel oder Karte antippen = anschubsen, Tasten `1`–`6`, `A` = alle, `P` = Party-Modus.

Nachfolger von [happyswing](https://github.com/joemoe/happyswing). Nächster Schritt: Bewegungsdaten echter Smartphones per MQTT statt Simulation.
